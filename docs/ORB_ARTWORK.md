# Orb artwork

Saved project asset: `public/assets/hero-orb-art.png` (1254 × 1254, RGBA with genuine transparency).

Method: built-in image-generation tool, using the original supplied mockup as a style reference. No CLI fallback was used. The original generated image was copied into the project without changing its pixels or transparency.

The WebGL component animates this artwork with gentle UV displacement and brightness shimmer. Its fallback uses the identical PNG, so the design remains consistent without WebGL. This replaces the previous procedural contour/plasma shader.
